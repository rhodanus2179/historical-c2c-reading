# 聖書の歴史を旅する365日

聖書を歴史の流れに沿って365日で読み進める、ブラウザ完結型の通読支援アプリです。

## 主な機能

- 365日分の歴史順通読計画
- 読了状況、読了日時、進捗率の保存
- 読了／未読操作の5秒間Undo
- 「次の通読」または「今日の予定」と閲覧中Dayの区別
- 日ごとのメモ
- 通読表の検索・絞り込み
- 聖書史タイムライン
- 「ともに聴く聖書」の各章への直接リンク
- ライト／ダークモード
- JSONバックアップ・復元
- バックアップ復元前の状態へのロールバック
- モバイル対応

## 使い方

`index.html` をブラウザで開くか、GitHub Pagesで公開して利用します。進捗やメモはブラウザの `localStorage` に保存されます。

「自分のペース」モードでは最初の未読Dayを「次の通読」として表示します。「カレンダー」モードでは開始日から算出したDayを「今日の予定」として表示します。過去や未来のDayを閲覧しているときは、現在の通読対象へ戻るボタンが表示されます。

## データについて

通読計画は、いのちのことば社 新改訳聖書センターの「聖書 新改訳 通読表【歴史順】」をもとに構成しています。

聖書本文・音声はアプリ内に収録せず、一般財団法人日本G&M文化財団の「ともに聴く聖書」へリンクします。

## 現在のバージョン

v1.3.0

## v1.2.1以前からの移行

既存の進捗、メモ、設定は起動時に自動的にv1.3形式へ移行されます。旧バージョンで読了済みだったDayも維持されますが、過去の読了日時は判定できないため、日時不明の記録として保持します。移行時点の日時を過去の読了日時として付与することはありません。

v1.3以降に読了したDayには、UTCの読了日時と読了時点のUTCオフセットを保存します。これは将来、曜日別・時間帯別の統計を正確に算出するための基礎データです。

## バックアップと復元

設定画面からJSONバックアップを保存できます。復元を行う直前の状態はブラウザ内に1件保存され、設定画面の「復元前の状態に戻す」から現在状態と入れ替えられます。

v1.2.1以前のバックアップも読み込めます。現在のアプリより新しい形式のバックアップは、データ破損を避けるため復元を拒否します。

## 構成

- `index.html` — アプリの入口
- `styles.css` — 表示スタイル
- `data/plan-*.js` — 365日分の通読計画
- `data/books.js` — 聖書66巻のPRSリンクコード
- `js/app-core.js` — 状態管理、移行、バックアップ、共通処理、聖書リンク解析
- `js/app-ui.js` — 画面描画、進捗、メモ、設定
- `docs/v1.3-design.md` — v1.3改修設計書

## 注意

進捗やメモは端末・ブラウザごとに保存されます。ブラウザデータの削除や端末変更に備えて、アプリの設定画面から定期的にバックアップしてください。
